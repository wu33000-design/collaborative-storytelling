# Unit 3｜讓故事發展起來

> 核心：故事不是很多事情接連發生，而是前一件事造成下一件事。

## 工具一｜因為 → 所以 → 但是

- **因為**：說明原因
- **所以**：前面的事情造成下一件事情
- **但是**：原本計畫遇到阻礙

示例：
1. 因為小美把鑰匙忘在教室
2. 所以她晚上偷偷回學校
3. 但是教室裡有人
4. 所以她躲在走廊
5. 但是那個人叫出了她的名字

## 工具二｜人物三問

問角色：
- 他想要什麼？
- 他害怕什麼？
- 他不能讓別人知道什麼？

最後再問：**他做了一個什麼選擇？**

如果人物的答案完全不會改變故事，表示人物還沒有真正進入故事。

## 卡住時

可以抽一張「故事阻礙」卡，但把它當備用工具，不要一開始就依賴抽卡。
